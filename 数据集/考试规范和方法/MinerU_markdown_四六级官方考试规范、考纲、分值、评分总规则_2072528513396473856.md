\# 一、四级（CET-4）整体架构、总分与分值分配（总分710分）

1. 写作（Writing） 占比15%，分值106.5分

考试时长：30分钟；要求：120–180词，应用文/议论文二选一；收卷先写，不可修改作答顺序

2. 听力理解（Listening） 占比35%，分值248.5分

短篇新闻3篇 7题；长对话2篇 8题；听力篇章3篇 10题

播放一遍，边听边涂卡，听力结束立即收答题卡1

3. 阅读理解（Reading） 占比35%，分值248.5分

选词填空（10题）+长篇段落匹配（10题）+仔细阅读（10题）

4. 翻译（Translation） 占比15%，分值106.5分

汉译英段落翻译，汉字总量140–160字，主题多为中国文化、社会、历史、经济

合格参考分数线：425分，可报名六级考试；无官方及格线，院校普遍以425作为通过标准

\# 二、六级（CET-6）整体架构、总分与分值分配（总分710分）

1. 写作（Writing） 占比15%，分值106.5分

考试时长30分钟；要求150–200词，议论文、图表作文、哲理谚语类题型为主

2. 听力理解（Listening） 占比35%，分值248.5分

长对话2篇；听力篇章3篇；讲座/讲话3篇，整体语速、词汇难度高于四级

3. 阅读理解（Reading） 占比35%，分值248.5分

选词填空、长篇匹配、仔细阅读题型结构不变，文章篇幅更长、生词更多、逻辑更深

4. 翻译（Translation） 占比15%，分值106.5分

汉译英段落180–200汉字，话题偏向社会发展、科技、传统文化、国家战略

【分类：官方规范｜四级作文五档官方评分细则（满分15分）】

一档（13–15分）：完全切题，行文连贯流畅，句式丰富多变，长短句搭配合理，用词精准高级，仅有极个别笔误，满足字数要求。

二档（10–12分）：整体紧扣主题，表达清晰通顺，逻辑连贯，存在少量轻微语法、拼写错误，不影响整体语义理解。

三档（7–9分）：基本切题，部分语句表意模糊，语法错误数量偏多，句式单一简单，存在少量漏写、字数不足问题。

四档（4–6分）：内容严重偏题，句式重复单调，语法错误密集，语句可读性差，大量信息表达不清。

五档（1–3分）：内容零散混乱、完全跑题，错误堆砌，无法识别完整语义，字数严重不足。

硬性扣分规则：

1. 书信、通知格式错误，酌情扣1–2分；

2. 全文抄袭题干原文超50%，直接判定最低档；

3. 字数低于100词统一降档扣分；

4. 大面积拼写错误、字迹潦草卷面脏乱降档处理。

【分类：官方规范｜六级作文五档官方评分细则（满分15分）】

一档（13–15分）：立意深刻，逻辑严谨分层清晰，句式灵活多样，词汇地道高级，几乎无语言错误，满足150词以上要求。

二档（10–12分）：主题明确，行文通顺，逻辑完整，零散小语法、用词瑕疵，不影响理解。

三档（7–9分）：勉强扣题，句式平淡基础，语法错误较多，部分句子表意模糊。

四档（4–6分）：偏离主题明显，语病频繁，句子破碎，可读性弱。

五档（1–3分）：内容杂乱、完全跑题，错误过多难以读懂。

硬性扣分：字数不足120词直接降档，照搬题干原文判定低分。

【分类：官方规范｜四级翻译五档评分细则（满分15分）】

一档（13–15）：完整覆盖全部原文信息，译文流畅地道，句式多变，用词精准，几乎无语法拼写错误，符合英文表达习惯。

二档（10–12）：完整传达原文含义，少量用词瑕疵、轻微语法错误，行文通顺。

三档（7–9）：翻译出核心大意，局部信息漏译，句式生硬存在中式英语，明显语法错误。

四档（4–6）：仅零散翻译片段，大量内容缺失，句式混乱错误繁多，可读性差。

五档（1–3）：译文严重偏离原意，语句不通，无法辨识有效语义。

【分类：官方规范｜六级翻译五档评分细则（满分15分）】

一档（13–15）：语义精准完整，句式丰富，用词正式地道，语序符合英文逻辑，笔误极少。

二档（10–12）：表意完整通顺，零星用词、语法小问题，不影响整体理解。

三档（7–9）：大体看懂主旨，部分内容漏译，中式英语明显，语法问题较多。

四档（4–6）：内容残缺严重，语病密集，翻译完整性不足。

五档（1–3）：译文混乱失真，无法理解原文含义。

【分类：官方规范｜客观题阅卷规则】

1. 听力、阅读全部选择题机器自动阅卷，每题固定分值，答对得分、答错不得分，无倒扣分；

2. 多项匹配类题目错一处整题不得分；

3. 答题卡填涂错位、漏涂、涂改模糊统一判定无效答案；

4. 作弊、雷同卷按考试违纪处理，成绩作废。

【分类：官方规范｜成绩说明规则】

1. 四级≥425分具备六级报考资格；

2. 成绩单终身有效，无有效期限制；

3. 成绩为常模参照赋分，不是原始卷面分数直接换算；

4. 缺考、违纪标记成绩无效，不予发放成绩单。
